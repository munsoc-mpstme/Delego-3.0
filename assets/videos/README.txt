Put the sponsor's video in this folder and name it:

    sponsor_video.mp4

Then rebuild the app (flutter run / flutter build apk). It plays at the top of the
Sponsors page. Until the file is here, the page shows a "Sponsor video coming soon"
placeholder. To use a different file name, change kSponsorVideoAsset in
lib/widgets/sponsor_video.dart.

Tip: keep it short and compressed (MP4 / H.264) so the app size stays small.
